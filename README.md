# Crimson_Barrage

**Crimson Barrage** é um protótipo de jogo *shmup 2D* desenvolvido com **Canvas API em JavaScript**, focado em movimentação simples e combate direto.

## Sobre o jogo

O jogador controla uma nave, movimentando-se livremente enquanto dispara contra ameaças. O objetivo é sobreviver o maior tempo possível mantendo controle e posicionamento.

## Controles

* W A S D — movimentação
* Enter — disparo

## Tecnologias utilizadas

* JavaScript (Canvas API)
* HTML5

## Status

Protótipo em desenvolvimento.

Este projeto foi criado com foco em prática de lógica de jogo, renderização com canvas e controle de input.

## Como executar

1. Clone o repositório:

2. Abra o arquivo `index.html` no navegador

## Objetivos do projeto

* Praticar desenvolvimento de jogos 2D
* Implementar movimentação e sistema de disparo
* Trabalhar com renderização manual usando Canvas
